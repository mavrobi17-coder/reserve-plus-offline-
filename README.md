# Офлайн профіль

Самостійний україномовний навчальний PWA-макет із головною сторінкою, профілем, локальними нотатками та декоративним QR-візерунком. **Не є офіційним «Резерв+», не формує військово-облікових документів і не підтверджує статус.**

## Запуск через GitHub Pages

1. Розпакуйте ZIP на Android.
2. Відкрийте репозиторій GitHub → Add file → Upload files і завантажте **шість файлів із папки** `reserve-plus-offline` у корінь репозиторію, а не сам ZIP.
3. Commit changes.
4. Settings → Pages → Build and deployment → Deploy from a branch → main → /(root) → Save.
5. Відкрийте опубліковану адресу Pages. Після першого завантаження сторінка працює офлайн завдяки service worker. Для встановлення на головний екран Android скористайтеся меню браузера «Додати на головний екран».

Дані зберігаються у localStorage пристрою. Очищення даних браузера може їх видалити. Не вводьте конфіденційні персональні дані в демонстраційний макет.
